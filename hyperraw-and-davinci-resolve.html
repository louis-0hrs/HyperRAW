Workflow guide

Different tools. One BRAW workflow.

DaVinci Resolve is a complete post-production environment. HyperRAW is a focused converter. The useful question is not which one “wins,” but which task needs to happen next.

The short answer

HyperRAW does not replace DaVinci Resolve. Blackmagic Design describes Resolve as an integrated post-production application covering editing, color correction, visual effects, motion graphics, audio post-production, media organization, and delivery. Resolve also supports Blackmagic RAW natively and exposes non-destructive RAW adjustments.

HyperRAW has a narrower purpose: it reads BRAW media through the Blackmagic RAW SDK and creates separate output files for downstream workflows. Its interface and command-line tool focus on file selection, batch processing, defined output settings, and conversion without requiring a Resolve project.

Choose according to the next task

Use DaVinci Resolve when the BRAW files are going into an edit or grade.

Keeping the camera originals native preserves Resolve’s documented BRAW controls and avoids an unnecessary intermediate generation.

Use HyperRAW when the required deliverable is a converted file rather than a creative project.

Examples include preparing media for software without BRAW support, producing a defined intermediate, generating review media, or applying one conversion setup to a batch.

Use both when conversion is one controlled step inside a larger post-production workflow.

HyperRAW can prepare specific handoff or review files while the verified BRAW originals remain available for native work in Resolve.

Three sensible workflow patterns

1. Native BRAW in Resolve

Camera originalCopy and verify the BRAW media.
DaVinci ResolveOrganize, edit, adjust RAW settings, grade, mix, and finish.
DeliveryRender the required master or distribution files.

This is generally the direct path when Resolve is already the editing and finishing environment.

2. HyperRAW before another system

Camera originalKeep verified BRAW masters and backups.
HyperRAWApply a defined decode and export configuration to selected files or a batch.
Downstream toolUse the supported intermediate, review, or delivery file.

This is useful when the receiving application, service, or person needs a format other than BRAW.

3. Automated preparation

Resolve may also participate later in the creative workflow; the CLI step is simply a focused conversion primitive.

What changes after conversion?

A converted file is not “better BRAW.” It is a new representation created from the decoded source. Depending on the output codec, bit depth, chroma sampling, resolution, bitrate, and color settings, conversion can preserve substantial visible information or discard information that the original retained.

RAW adjustments can also become baked into the exported pixels. If the next stage is Resolve and the team expects to change BRAW decode settings, use the original BRAW media unless a documented workflow requirement says otherwise.

Archive principle: Keep verified BRAW camera originals when future re-grading, re-export, evidence, or archival value matters. Treat converted media as derivatives unless your own retention policy explicitly defines otherwise.

Frequently asked questions

Does HyperRAW replace DaVinci Resolve?

No. Resolve is a complete post-production application. HyperRAW is a focused converter for file, folder, batch, and command-line workflows.

Do I need DaVinci Resolve installed to use HyperRAW?

No. HyperRAW uses the Blackmagic RAW SDK directly and does not require Resolve to be installed.

Should I convert BRAW before using DaVinci Resolve?

Not by default. Resolve supports BRAW natively and exposes RAW controls. Convert only when a workflow requires a particular intermediate, review file, automated handoff, or compatibility with another system.

Can HyperRAW output be used in DaVinci Resolve?

Yes, when the selected output codec and container are supported by the installed Resolve version. The converted file is not the original BRAW camera file and may not retain the same RAW adjustment flexibility.

Which tool should I use for color grading?

DaVinci Resolve. HyperRAW can apply decode and export settings, but it is not positioned as a creative color-grading application.
