How to convert BRAW files on Windows

Start with a short clip and an empty output folder. Keep the BRAW camera original: an exported video is a new file with the chosen decode settings baked into its pixels.

  1. Install HyperRAW. Download the x64 installer and run it on Windows 10 or 11. The current build is unsigned, so Windows SmartScreen may display an unknown-publisher warning. Release notes and checksums are available with the download.
  2. Add BRAW footage. Select your .braw files or add a folder to the queue. Choose the free mode or activate your license.
  3. Choose an output format. Use H.264/MP4 or H.265/HEVC for a compact delivery file, or an appropriate MOV intermediate for an editing workflow. Confirm the container and encoder choices in the app.
  4. Set size, decoder, and destination. Auto is a useful starting point for device selection. Set the output scale or maximum width to suit the receiving application.
  5. Convert and check the result. Review both per-file and batch progress, then open a completed file in the program that will use it.

For a closer look at the interface and shared export workflow, see BRAW to MP4 and MOV conversion.

CUDA, OpenCL, and CPU decoding

On Windows, HyperRAW can decode BRAW using NVIDIA CUDA, compatible OpenCL devices from AMD, Intel, or NVIDIA, or the CPU. A dedicated GPU is optional. The options shown depend on your hardware and drivers.

Decoding and encoding are separate choices. A CUDA decoder reads the BRAW frames; the selected output encoder writes the new video. Hardware encoding requires a compatible GPU, driver, and encoder implementation. The Windows release tests encoder availability with an actual encode before starting the job.

For delivery

H.264 and HEVC are useful when you need viewing or distribution copies. Playback compatibility, resolution limits, and bit depth depend on the selected encoder and receiving device.

For editing or archiving

Choose an available ProRes-compatible or CineForm-compatible intermediate for a supported editing workflow, or FFV1 for lossless output. Image sequences are also available; check the format and depth your next tool expects.

Batch BRAW conversion from PowerShell

The Windows installation includes bin\hyperraw_cli.exe. It can become the conversion step inside a script or scheduled job. This example writes a lossless FFV1 output to an existing folder:

hyperraw_cli.exe convert --input "C:\footage\clip.braw" --output "C:\exports" --codec ffv1 --overwrite

See HyperRAW CLI and automation for options, exit codes, and a PowerShell folder-processing example.

Windows conversion questions

Can I convert BRAW to MP4 without DaVinci Resolve?

Yes. HyperRAW uses the Blackmagic RAW SDK and does not require Resolve to be installed. Choose a supported MP4 output in HyperRAW. If your task is native RAW editing or grading, see how HyperRAW and DaVinci Resolve fit together.

Can I try BRAW conversion for free?

Every application start includes two successful free exports. Output up to 4096 × 2304, including the portrait equivalent, has no watermark. Larger free exports receive a watermark. A license removes the free-mode limits.

Does Windows conversion require an NVIDIA GPU?

No. CPU decoding is supported, and compatible OpenCL hardware is another option. Available output encoders depend on the system; a GPU used for decoding does not guarantee support for every export format.

Using a Mac instead?

The Apple silicon version has its own hardware and export options. Read the BRAW conversion guide for Apple Mac, or start with what a BRAW file contains.
