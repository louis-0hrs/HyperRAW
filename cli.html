CLI & automation

Bring BRAW conversion into your workflow.

The Windows package includes hyperraw_cli.exe: a real command-line converter for scripts, servers, scheduled jobs, and agentic media pipelines. Give it a BRAW file, an existing output folder, and a codec—then make conversion a dependable building block in your own system.

Download for WindowsDownload User Guide

Included with HyperRAW

Find the executable in the Windows package at bin\hyperraw_cli.exe. No separate developer download is required.

Made for orchestration

Use it from PowerShell, task schedulers, server-side services, media automation, or agentic workflows that need a focused conversion step.

Explicit by design

Each run declares its input, output directory, codec, and optional encoder. That makes jobs easy to reproduce, inspect, and retry.

A dependable conversion primitive for your pipeline.

HyperRAW CLI is ideal when a person, script, service, or AI agent has already decided what needs to be converted. It handles the BRAW conversion step while your workflow keeps control of the surrounding logic: file discovery, scheduling, review, delivery, and retries.

Start with one clear command

Convert one BRAW clip to a lossless FFV1 output and explicitly allow an existing file to be replaced.

hyperraw_cli.exe --input "C:\incoming\clip.braw" --output "C:\exports" --codec ffv1 --overwrite

The input must be a BRAW file and the output directory must already exist. The command reports status and progress while it runs.

Everything you can control

--input <file>Required BRAW source file.
--output <directory>Required existing destination folder.
--codec <name>Choose the output codec.
--encoder <name>Use an explicit FFmpeg encoder, for example libx265.
--bit-depth <8|10|16>Set the requested output bit depth.
--overwriteReplace existing output without stopping for confirmation.
--versionPrint the installed HyperRAW version.
--helpShow the complete command reference.

Codec choices

Choose the format that fits the next stage of your workflow. HyperRAW CLI accepts:

  • h264 — 8-bit delivery output
  • h265 / hevc — 10-bit HEVC
  • av1 and vp9 — 10-bit modern delivery formats
  • prores and cineform — 10-bit edit-friendly intermediates
  • ffv1 — 16-bit lossless archival output

Each codec chooses a sensible default bit depth; use --bit-depth when your pipeline needs an explicit value.

HEVC with an explicit encoder

Use a specific FFmpeg encoder when you need predictable routing in an established processing environment.

hyperraw_cli.exe --input "C:\incoming\clip.braw" --output "C:\exports" --codec h265 --encoder libx265 --bit-depth 10 --overwrite

Process a folder from PowerShell

Keep your own orchestration layer and call HyperRAW once per source clip.

$destination = 'C:\exports'
Get-ChildItem 'C:\incoming' -Filter *.braw | ForEach-Object {
  & .\hyperraw_cli.exe --input $_.FullName --output $destination --codec h265 --overwrite
  if ($LASTEXITCODE -ne 0) { throw "HyperRAW failed: $($_.Name)" }
}

Fits cleanly into automated systems

HyperRAW CLI prints conversion status and progress while it works. Your workflow can use its exit code to decide what happens next:

0Conversion completed successfully.
1Input probing or conversion failed.
2Invalid arguments, missing input, or missing output directory.
