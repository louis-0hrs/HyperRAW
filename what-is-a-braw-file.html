What is a BRAW file?

A practical explanation of Blackmagic RAW camera files: what they contain, how metadata and compression work, which software can open them, and what changes when you convert them.

Reviewed against Blackmagic Design documentation · July 29, 2026

Extension.braw
Created forCamera acquisition and post-production
Key distinctionEncoded image data plus camera and lens metadata

The short answer

A BRAW file is a clip recorded in Blackmagic Design’s Blackmagic RAW format. The filename normally ends in .braw. It contains encoded image information together with metadata that software can use when decoding and presenting the clip.

Blackmagic RAW is designed for camera acquisition and post-production. It is not simply another name for an MP4 or MOV file. A conventional delivery file normally contains video that has already been processed into a selected color representation. A BRAW workflow retains adjustable camera-related information for the decode stage.

Terminology matters: Blackmagic RAW is the product and format name; .braw is the file extension. “BRAW” is a common short form. These names belong to Blackmagic Design and are used on this page only to identify the format.

What is stored in a BRAW file?

According to Blackmagic Design, part of the de-mosaic process is performed in the camera. The resulting partially de-mosaiced image data is stored together with information about the camera sensor. Compatible decoding software uses that information to render the image.

A clip can also carry descriptive metadata. Blackmagic’s documentation lists examples such as lens information, iris, ISO, color space, and slate information. Some metadata can vary by frame. A separate human-readable .sidecar file can override supported metadata without rewriting the original embedded values.

That distinction is useful in practice: changing a supported RAW setting in compatible software does not necessarily mean rewriting the camera original. The exact controls available still depend on the application, SDK integration, camera, recording settings, and software version.

How BRAW compression works

Blackmagic RAW offers two families of recording settings. Availability can differ between cameras and firmware versions:

MethodExamples documented by BlackmagicPractical effect
Constant bitrate5:1, 8:1, 12:1, 18:1Aims for more predictable data rates and file sizes. The ratio is relative to unprocessed sensor-frame data.
Constant qualityQ0, Q1, Q3, Q5Allows the data rate to vary with image complexity in order to target a selected quality level.

These settings should not be reduced to a universal “lossless versus lossy” label. Blackmagic describes high-end settings using terms such as “visually lossless,” but that is not the same as a guarantee of mathematical losslessness for every BRAW mode. The chosen setting affects file size, data rate, and retained detail.

How can you open a BRAW file?

Blackmagic Design provides direct BRAW support in DaVinci Resolve and offers Blackmagic RAW Player. Other applications can add support through Blackmagic Design’s publicly available SDK. The existence of an SDK does not mean every video player or editor supports BRAW automatically.

If a program cannot import a .braw clip, check the program version, operating-system support, installed components, and the vendor’s current compatibility documentation. Renaming the extension does not convert the underlying media.

When does converting BRAW make sense?

Conversion can be useful when the next tool in a workflow does not support BRAW, when a standardized intermediate is required, or when a smaller viewing or delivery copy is needed. Common reasons include:

  • Compatibility: creating media for an editor, review system, archive tool, or delivery platform that does not accept BRAW.
  • Repeatability: applying one defined decode and export configuration to a group of clips.
  • Performance: preparing an editing-friendly intermediate or a lighter review copy.
  • Delivery: producing a file intended for playback rather than further RAW adjustment.

Conversion is not an automatic quality improvement. Depending on the selected output codec, bit depth, chroma sampling, resolution, and bitrate, the new file may retain much of the visible information or discard a significant amount. RAW-related adjustments may also become baked into the exported pixels.

Keep the camera original. When re-grading, future reprocessing, or archival value matters, retain verified backups of the original .braw files. A delivery copy is not a substitute for a camera master.

BRAW, MP4, and MOV are not interchangeable terms

MP4 and MOV are containers. A container can hold video, audio, timecode, and other data, but the codec inside determines how the video itself is encoded. Two files ending in .mp4 or .mov can therefore have very different technical properties.

TermWhat it describesTypical purpose
BRAWA camera recording format and codec with RAW-oriented decode controls and metadata.Acquisition and post-production.
MP4A media container; the contained codec must be specified separately.Playback, review, streaming, or delivery.
MOVA media container that can carry several different video codecs.Editing intermediates, production exchange, or delivery.

Frequently asked questions

What programs can open a BRAW file?

DaVinci Resolve and Blackmagic RAW Player support .braw files. Other applications may support them through Blackmagic Design’s SDK or their own integration. Available controls vary by application and version.

Is BRAW the same as MP4 or MOV?

No. Blackmagic RAW is a camera recording format and codec. MP4 and MOV are containers that can hold different encoded video and audio formats.

Does converting BRAW improve image quality?

No. Converting BRAW cannot add sensor detail that was not recorded. It can make media more compatible or practical, but output settings can also discard color, tonal, spatial, or temporal information.

Should I delete BRAW originals after conversion?

Usually not. A converted file may be easier to edit or deliver, but it can bake in image decisions and discard some flexibility. Keep verified camera originals and backups when future re-grading or archival value matters.

Is every BRAW file lossless?

No blanket lossless claim should be made. Blackmagic RAW offers multiple constant-bitrate and constant-quality compression settings. The selected camera setting affects data rate, file size, and retained detail.
