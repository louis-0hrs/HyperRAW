Install the BRAW converter on your Mac

The current Mac release is built for Apple silicon (arm64), with macOS 13 or later. It is not an Intel Mac or universal build. Download the DMG, open it, and copy HyperRAW.app into your Applications folder.

The Mac build is unsigned and has not been notarized by Apple. Gatekeeper may display a warning or block it from opening. Read the macOS release notes, checksums, and distribution details before installing.

How to convert BRAW to MOV or MP4 on macOS

  1. Add the .braw clips. Open HyperRAW and select files or a folder. The file queue keeps the conversion job separate from an editing timeline.
  2. Choose your export. Select native Apple ProRes for an appropriate MOV editing intermediate, or a supported H.264/HEVC output for a smaller delivery file.
  3. Choose scale and processing. Start with Auto decoding, or select Metal or CPU. Set the output scale or maximum width for the receiving workflow.
  4. Convert the batch. Pick a destination, start conversion, and follow the individual file and overall progress. Check a completed export in the application that will receive it.

Keep the original BRAW files. Exporting to MOV or MP4 creates a new representation and can bake in RAW adjustments; it does not preserve the original camera file's full editing flexibility.

Apple ProRes and Metal on Apple silicon

Native Apple ProRes

The Mac app offers native Apple ProRes separately from FFmpeg software ProRes. Choose the implementation and profile that fit your editing pipeline. Version 2026.11.2 fixes native ProRes exports that combine maximum-width limits and output resizing.

Metal or CPU decoding

Metal provides the GPU decoding path on Apple silicon, with CPU decoding also available. This choice reads the BRAW source; it is separate from the encoder selected for the output file.

Format availability depends on the system and the selected output settings. Resolution, memory use, and processing speed also depend on your source footage. Try a short representative clip before committing a large queue.

Automate Mac BRAW conversion from Terminal

The Mac app bundle includes Contents/MacOS/hyperraw_cli. After copying the app to Applications, invoke the converter directly. This example exports FFV1 to an existing folder:

"/Applications/HyperRAW.app/Contents/MacOS/hyperraw_cli" convert --input "$HOME/Movies/clip.braw" --output "$HOME/Movies/exports" --codec ffv1 --overwrite

Use --help for the installed version's options. The CLI and automation guide covers arguments and exit codes for integrating conversion into a wider media workflow.

Mac conversion questions

Can I convert BRAW on an Apple silicon Mac?

Yes. HyperRAW 2026.11.2 supports Apple silicon Macs running macOS 13 or later, with Metal and CPU decoding. The download is an arm64 DMG; Intel Macs are not supported by this release.

Is BRAW conversion on Mac free to try?

Yes. Each application start includes two successful free exports. Output up to 4096 × 2304, or the portrait equivalent, has no watermark; larger free exports receive a watermark. A license unlocks uninterrupted full-resolution workflows.

Does a ProRes export replace my BRAW original?

No. ProRes is an intermediate output for a compatible workflow. Keep the original BRAW for future RAW adjustments and re-exports. For native editing and grading, read when to use DaVinci Resolve alongside HyperRAW.

Working across Mac and Windows?

HyperRAW also provides a Windows x64 installer with CUDA, OpenCL, and CPU options. See BRAW conversion on Windows for that setup, or read the guide to Blackmagic RAW files before choosing an export format.
